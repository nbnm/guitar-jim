# Popular-song practice studies

Updated 29 October 2026. Sixteen popular-song studies, in addition to five originals and the existing U2 exercise, give a 22-song starter library. The latest six additions are three each by Ed Sheeran and Imagine Dragons. Each is an authored eight-bar exercise in standard tuning with **no capo**, matching the user's current guitar setup. The practice tempo, strumming and spacing are chosen for learning. These loops do not represent complete transcriptions or timing maps of the recordings. They contain no third-party lyrics, melodies, fret tablature, audio or artwork.

The new studies are ready to use as authored exercises. Users can change the tempo, capo, chords and patterns in the editor. The U2 factory arrangement retains its original review requirements; the user's already reviewed no-capo U2 version is preserved during catalog seeding.

## Pattern controls

Eight reusable presets cover half-time, steady downstrokes, eighth-note pickups, country pulse, folk groove, syncopation, driving downstrokes and alternating eighths. Presets alter strum events only; existing chords and lyrics remain intact. Missing events display as rests. Custom per-bar strokes are stored in the same arrangement schema as imported or original songs.

The live pattern strip and optional chord table use the same practice beat and eighth-note subdivision. The table displays chord changes on their actual beat and holds a chord with an em dash between changes. Current-bar highlighting remains while paused; subdivision highlighting runs only while playing. Arrow direction is visual guidance rather than a claim that the microphone measures hand motion.
